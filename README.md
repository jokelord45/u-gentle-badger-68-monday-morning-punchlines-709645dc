One joke about Monday mornings, no longer than 200 characters: the alarm clock itself refuses to get up, snoozing its own ring and calling in sick — a Monday-morning joke where even the machine that is supposed to wake you gives up first.

## Run

```
node main.ts
```

This writes the joke to `/output/entry.txt`.
